NodeJS Semver Updater is an open-source npm package for updating a NodeJS project’s version values as part of a repeatable release workflow.

## Quick Info

- [View the package on npm](https://www.npmjs.com/package/@bigfootds/nodejs-semver-updater)
- [View the source on GitHub](https://github.com/BigfootDS/pkg-nodejs-semver-updater)

## What it provides

It is the NodeJS member of the BigfootDS semantic-versioning tooling suite and keeps version changes close to the code and automation that release a project.
