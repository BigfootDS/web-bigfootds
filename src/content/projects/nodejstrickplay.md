NodeJS Trickplay is an open-source npm package for generating trickplay images from video files for NodeJS applications.

## Quick Info

- [View the package on npm](https://www.npmjs.com/package/@bigfootds/nodejs-trickplay)
- [View the source on GitHub](https://github.com/BigfootDS/pkg-nodejs-trickplay)

## What it provides

The package supports video-processing workflows that need preview or navigation imagery without making every consuming project build that pipeline from scratch.
