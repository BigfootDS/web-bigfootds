Unreal Semver Updater is an open-source npm package that updates the version values of an Unreal Engine project from a NodeJS release workflow.

## Quick Info

- [View the package on npm](https://www.npmjs.com/package/@bigfootds/unreal-semver-updater)
- [View the source on GitHub](https://github.com/BigfootDS/pkg-unreal-semver-updater)

## What it provides

It provides the Unreal Engine member of the BigfootDS semantic-versioning tooling suite, helping a project keep its release version information consistent.
