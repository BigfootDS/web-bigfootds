Godot Semver Updater is an open-source npm package for updating the version values in a Godot project with a predictable semantic-versioning format.

## Quick Info

- [View the package on npm](https://www.npmjs.com/package/@bigfootds/godot-semver-updater)
- [View the source on GitHub](https://github.com/BigfootDS/pkg-godot-semver-updater)

## What it provides

It is part of the BigfootDS semantic-versioning tooling suite, giving Godot projects a small, reusable version-update step for release workflows.
