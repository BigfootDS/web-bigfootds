BigfootDS Stream Dock Icons is an open-source icon pack for MiraBox Stream Dock hardware. It brings BigfootDS project, game, application and computer-operation imagery into a compact control surface.

## Quick Info

- [View the source on GitHub](https://github.com/BigfootDS/bigfootds-stream-dock-icons)

## What it provides

The pack is designed for practical daily use on supported Stream Dock products, with icons that make BigfootDS tools and common computer actions easier to recognise at a glance.
