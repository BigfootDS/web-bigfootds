Game Automated Semver is an open-source GitHub Action that automates a game project’s semantic versioning as part of its GitHub Actions workflow.

## Quick Info

- [View the source on GitHub](https://github.com/BigfootDS/actions-game-automated-semver)

## What it provides

The action turns a recurring game-release chore into a reviewable automation step, keeping version changes visible in the same workflow that builds and publishes a project.
